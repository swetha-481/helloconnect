# CareConnect

CareConnect is a web-based platform designed to connect people who want to donate unused medicines with those who need them.

The goal of this project is to reduce medicine wastage and improve accessibility by creating a simple system for donating and requesting medicines.

---

## Problem

Many unused medicines are discarded even when they are still usable. At the same time, some people struggle to access basic medications.

There is no structured way for individuals to donate unused medicines safely to those in need.

---

## Solution

CareConnect provides a platform where:

* Donors can list unused medicines
* Users can request available medicines
* Prescriptions can be uploaded for verification

The system helps ensure responsible sharing while improving access.

---

## Key Features

* User registration and login
* Medicine donation listing
* Medicine request system
* Prescription upload support
* Request tracking
* Firebase-based authentication

---

## System Workflow

User Registration
→ Login
→ Donate Medicine / Request Medicine
→ Upload Prescription (if required)
→ Review & Approval
→ Request Fulfillment
